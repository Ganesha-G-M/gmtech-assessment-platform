# Python Assessment Question Bank

Python syntax, data structures, functions, files, exceptions, OOP, and problem solving.

## MCQ Set (20 Questions)

1. Which data type is immutable in Python?
   A. list
   B. dict
   C. set
   D. tuple
   Answer: D

2. Which keyword defines a function?
   A. func
   B. def
   C. function
   D. lambda only
   Answer: B

3. What is the output type of input()?
   A. int
   B. str
   C. float
   D. bool
   Answer: B

4. Which structure stores key-value pairs?
   A. list
   B. tuple
   C. dict
   D. set
   Answer: C

5. Which statement handles exceptions?
   A. try/except
   B. if/else
   C. for/else only
   D. catch/finally only
   Answer: A

6. What does len([1, 2, 3]) return?
   A. 2
   B. 3
   C. 4
   D. Error
   Answer: B

7. Which operator performs floor division?
   A. /
   B. //
   C. %
   D. **
   Answer: B

8. Which method adds an item to the end of a list?
   A. add
   B. append
   C. insertEnd
   D. push
   Answer: B

9. What does range(3) generate?
   A. 1,2,3
   B. 0,1,2
   C. 0,1,2,3
   D. 3 only
   Answer: B

10. Which keyword creates a class?
   A. object
   B. class
   C. struct
   D. typeclass
   Answer: B

11. Which expression creates a set?
   A. []
   B. {} with key:value
   C. {1, 2, 3}
   D. ()
   Answer: C

12. What does PEP 8 define?
   A. Database rules
   B. Python style guide
   C. Compiler internals
   D. Package installer
   Answer: B

13. Which file mode opens a file for appending?
   A. r
   B. w
   C. a
   D. x only
   Answer: C

14. What is list comprehension used for?
   A. Creating lists concisely
   B. Deleting variables
   C. Importing modules
   D. Handling threads only
   Answer: A

15. Which module is commonly used for JSON parsing?
   A. csv
   B. json
   C. pickle only
   D. os
   Answer: B

16. What does is compare?
   A. Object identity
   B. Only numeric equality
   C. String length
   D. Dictionary keys
   Answer: A

17. Which keyword exits a loop immediately?
   A. skip
   B. break
   C. continue
   D. pass
   Answer: B

18. Which keyword skips to the next loop iteration?
   A. break
   B. continue
   C. pass
   D. return
   Answer: B

19. What does *args collect?
   A. Keyword arguments
   B. Variable positional arguments
   C. Class attributes
   D. Environment variables
   Answer: B

20. Which method converts a string to lowercase?
   A. lower()
   B. down()
   C. casefold only
   D. small()
   Answer: A
