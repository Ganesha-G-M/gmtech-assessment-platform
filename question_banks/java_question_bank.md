# Java Assessment Question Bank

Java syntax, OOP, collections, exceptions, streams, concurrency, and problem solving.

## MCQ Set (20 Questions)

1. Which keyword is used to inherit a class in Java?
   A. implements
   B. extends
   C. inherits
   D. super
   Answer: B

2. Which collection does not allow duplicate elements?
   A. List
   B. Set
   C. Queue
   D. ArrayList
   Answer: B

3. What is the default value of an int instance variable?
   A. null
   B. 0
   C. 1
   D. undefined
   Answer: B

4. Which method is the entry point of a standard Java application?
   A. start()
   B. main()
   C. run()
   D. init()
   Answer: B

5. Which keyword prevents a class from being inherited?
   A. static
   B. final
   C. private
   D. sealedonly
   Answer: B

6. Which exception type is checked at compile time?
   A. NullPointerException
   B. IOException
   C. ArithmeticException
   D. ArrayIndexOutOfBoundsException
   Answer: B

7. What does JVM stand for?
   A. Java Variable Machine
   B. Java Virtual Machine
   C. Java Verified Method
   D. Joint Virtual Module
   Answer: B

8. Which operator compares object references?
   A. equals()
   B. ==
   C. compareTo()
   D. instanceof only
   Answer: B

9. Which interface is commonly used for sorting objects naturally?
   A. Runnable
   B. Comparable
   C. Serializable
   D. Cloneable
   Answer: B

10. Which access modifier is most restrictive?
   A. public
   B. protected
   C. private
   D. default
   Answer: C

11. What is method overloading?
   A. Same method name with different parameters
   B. Changing superclass method behavior
   C. Using private methods only
   D. Running multiple threads
   Answer: A

12. Which block always runs after try/catch unless the JVM exits?
   A. throw
   B. finally
   C. final
   D. default
   Answer: B

13. Which class is immutable?
   A. String
   B. StringBuilder
   C. ArrayList
   D. HashMap
   Answer: A

14. Which package contains ArrayList?
   A. java.io
   B. java.util
   C. java.net
   D. java.sql only
   Answer: B

15. Which keyword creates an object?
   A. class
   B. new
   C. object
   D. make
   Answer: B

16. What does static mean for a variable?
   A. Belongs to the class
   B. Belongs only to one object
   C. Cannot change ever
   D. Is stored in a file
   Answer: A

17. Which stream operation transforms each element?
   A. filter
   B. map
   C. collect
   D. sorted only
   Answer: B

18. Which interface represents a task run by a thread?
   A. Runnable
   B. Iterable
   C. Comparator
   D. AutoCloseable
   Answer: A

19. What is encapsulation?
   A. Hiding data behind methods
   B. Copying objects
   C. Compiling bytecode
   D. Deleting unused methods
   Answer: A

20. Which keyword is used to handle an exception?
   A. catch
   B. error
   C. rescue
   D. handle
   Answer: A

2. Write a method to check whether a number is prime.
3. Write a program to count character frequency in a string.
4. Write a method to find the second largest element in an array.
5. Write a program to remove duplicates from an ArrayList while preserving order.
6. Write a method to check whether two strings are anagrams.
7. Write a program to implement binary search on a sorted array.
8. Write a class BankAccount with deposit, withdraw, and balance methods.
9. Write a program to sort students by marks using Comparator.
10. Write a method to calculate factorial using recursion.
11. Write a program to read integers and print only even numbers.
12. Write a method to merge two sorted arrays.
13. Write a program to find the first non-repeating character in a string.
14. Write a method to validate balanced parentheses using Stack.
15. Write a program to demonstrate try-catch-finally with file reading.
16. Write a method to find common elements between two arrays.
17. Write a Java stream pipeline to filter names starting with A and collect them.
18. Write a program to create and start two threads that print numbers.
19. Write a method to detect a palindrome string ignoring case.
20. Write a simple Employee class and override toString(), equals(), and hashCode().
